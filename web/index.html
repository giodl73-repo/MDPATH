Workbench limits: 128 KiB UTF-8 and 8,192 lines of Markdown; 4,096 URI bytes; 1,024 logical path bytes; 1 MiB request. Decimal runs in address fragments must fit unsigned 32-bit values for portable numeric behavior. These are companion admission rules, not changes to the native URI grammar. Worker startup/computation deadlines are 12/10 seconds; local reads recover after five seconds.
Input Markdown downloads preserve opened UTF-8 text and CRLF until editing, successful replacement or restoring an example. Current-request exports use the current editor text. Failed reads retain the previous draft. Named addresses do not guarantee identity across arbitrary renaming or document changes.
